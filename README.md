# The Paper Orchard

A six-page website that presents a short story like a book: a home page with the cover, summary and contents, followed by five chapter pages.

The story follows Lina, who receives a seed folded from paper, plants it in her grandmother's courtyard, and watches it grow into a tree of unsent letters.

## Pages

| Page | File |
|------|------|
| Home: cover, summary, contents, quote | `index.html` |
| Chapter 1: The seed in the envelope | `chapter-1.html` |
| Chapter 2: Planting words | `chapter-2.html` |
| Chapter 3: The orchard wakes | `chapter-3.html` |
| Chapter 4: The dry season | `chapter-4.html` |
| Chapter 5: What the trees remember | `chapter-5.html` |

## What I built

- A navigation bar on every page, laid out with Flexbox (logo on the left, chapter links on the right)
- A contents section on the home page built with a description list (`<dl>`), linking to each chapter
- Back and Next buttons on each chapter so the site reads like a book, with the last chapter leading back to the start
- A quote on the home page that links to the exact sentence it comes from in Chapter 1, using an anchor (`#quote`)
- One shared stylesheet for all pages, with a consistent sage and green color palette
